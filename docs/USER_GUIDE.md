# Code Déjà Vu 操作指南

Code Déjà Vu 用来统一查看和管理 Claude Code、Codex CLI 与 OpenCode 留在本机的会话、
指令和配置资料。本指南以当前公开版本为准；不同 Agent 支持的功能会略有差异。

## 安装与首次启动

### 1. 下载

前往 [GitHub Releases](https://github.com/jnchen/code_dejavu/releases/latest)：

- `code-dejavu_*_x64-setup.exe`：Windows NSIS 安装包，推荐普通用户使用。
- `code-dejavu_*_x64_en-US.msi`：Windows MSI 安装包，适合需要 MSI 的场景。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值。

### 2. 准备本地 Agent 数据

应用不需要单独登录，它会读取当前系统用户已有的本地资料：

| 来源 | 主要会话位置 | 说明 |
| --- | --- | --- |
| Claude Code | `~/.claude/projects/` | 同时支持规则、记忆、指令与工作流 |
| Codex CLI | `~/.codex/sessions/` | 会话通常按日期分目录保存 |
| OpenCode | `~/.local/share/opencode/opencode.db` | 会话保存在 SQLite 数据库中 |

`~` 表示当前用户主目录。如果某个 Agent 从未运行、尚未产生会话，或数据目录不在应用支持的
默认位置，对应来源会显示“未发现本地数据”。

### 3. 等待首次索引

首次启动后，应用会在后台建立搜索索引。请保持窗口开启，直到控制台的“搜索索引”显示
“已索引”。索引完成前，会话搜索、用量统计、摘要和最后交互时间可能不完整。

## 五分钟上手

1. 打开 **控制台**，确认 Claude Code、Codex CLI 或 OpenCode 至少有一个来源可用。
2. 等待搜索索引完成；如果刚产生了新会话，可点击 **刷新**，必要时点击 **重建索引**。
3. 进入 **会话档案**，选择来源和“当前 / 全部 / 归档”范围。
4. 打开一条会话，浏览时间线；需要时使用会话内搜索、收藏、置顶、备注或导出。
5. 进入 **用量**，查看按来源、模型、项目和日期聚合的 token 统计。

## 页面功能

### 控制台

控制台用于快速确认应用状态：

- **搜索索引**：显示已索引会话数、词条数和解析失败数。
- **来源状态**：显示各 Agent 是否存在本地数据，以及当前会话数量。
- **活动趋势**：展示最近 30 天的会话活跃度。
- **最近会话**：直接回到最近的编码工作。
- **活跃项目**：按会话数列出常用项目。

**刷新**用于重新读取当前摘要；**重建索引**会重新扫描 Agent 会话数据，耗时取决于会话数量
和文件大小。

### 会话档案

#### 筛选与搜索

- 顶部来源按钮可切换 Claude Code、Codex CLI、OpenCode 或统一时间线。
- **当前**只显示未归档会话，**归档**只显示快照中的会话，**全部**同时显示两者。
- 可将搜索范围限制为 **对话**、**工具**或**思考**内容。
- 普通搜索使用本地索引，速度快，但索引会对超大内容做容量限制。
- **深度全文**直接扫描会话源文件，速度较慢，适合查找普通搜索遗漏的精确内容。

如果刚结束或继续了一条会话但列表尚未更新，先点击 **索引**，等待重建完成后再搜索。

#### 查看会话

打开会话后可以：

- 在“对话”和“+工具”两种显示级别之间切换。
- 向上加载更早记录，或点击 **最新**回到尾部。
- 查看工具调用、文件修改、终端输出、思考块和子代理记录。
- 使用“在此会话中搜索”定位当前会话里的内容。
- 复制会话 ID，或将整段会话复制、导出为 Markdown。
- 查看会话对应的项目路径、创建时间、最后交互时间和模型信息。

导出的 Markdown 会包含真实会话内容，分享前请再次脱敏。

#### 收藏、置顶、标签与备注

收藏、置顶、标签和备注只保存在 Code Déjà Vu 的本地数据中，不会改写原始 Agent 会话文件。
列表中的 **★ 收藏**可快速筛选已收藏会话。

#### 恢复会话

支持恢复的当前会话会显示 **恢复会话**。点击后，应用会在该项目目录打开设置中选定的终端，
并调用对应 Agent CLI 的恢复命令。

恢复前请确认：

1. 对应 CLI 已安装且能在终端的 `PATH` 中直接运行。
2. **设置 → 终端**中的 Shell 类型正确。
3. 自定义恢复参数和环境变量没有互相冲突。
4. 归档会话通常只能查看，不能直接恢复。

#### 项目上下文

会话详情中的 **项目上下文**会显示当前项目的指令、规则、记忆和项目级设置。带有“编辑”、
“创建”、“启用”或“停用”的操作会直接修改项目中的真实文件，请先确认 Git 状态或做好备份。

### 工作流

工作流页集中浏览本地的技能、命令、计划和任务，目前主要来自 Claude Code 的
`~/.claude/skills/`、`commands/`、`plans/` 和 `tasks/`：

- 可按类型筛选或按名称、描述搜索。
- 点击项目可查看 Markdown 内容。
- **在文件管理器中打开**可以定位到源文件。
- 新增文件后点击 **重新扫描**。

### 记忆

记忆页按来源和项目展示 Agent 记忆：

- 可按反馈、项目、用户、引用等类型筛选。
- 支持查看元数据和 Markdown 正文。
- 支持写入的来源可以新建、编辑和删除记忆。
- 删除操作会永久删除本机真实文件，无法从应用内撤销。

Codex 记忆通常是只读的；OpenCode 当前不提供记忆管理。最终以界面是否显示编辑按钮为准。

### 规则

规则页展示各 Agent 的全局规则：

- “全部”视图只读；选择具体来源后才能执行该来源支持的管理操作。
- Claude Code 规则支持启用和停用。
- Codex CLI 与 OpenCode 的规则目前以只读查看为主。

规则切换会修改真实规则文件，修改后建议重新打开对应 Agent 验证效果。

### 工具

工具页只读汇总 MCP 服务器和 Hooks 配置：

- 显示来源、作用域、启用状态、命令和参数。
- 环境变量或 Header 的敏感值会隐藏，只显示键名。
- 如需编辑，请前往 **设置**中的全局配置，或在会话的 **项目上下文**中修改项目配置。

### 用量

用量页根据当前会话的搜索索引统计：

- 总会话数以及输入、输出、缓存和总 token。
- 按来源、模型、项目和日期聚合。
- 按设置中的价格表粗略估算成本。

价格按模型名子串匹配，单位为 USD / 100 万 tokens；缓存 token 按输入价格的 `0.1×`
估算。该结果只供参考，不应代替服务商账单。

### 快照

> [!CAUTION]
> **“创建快照”是归档/切换操作，不是普通的只读备份。** 应用会先复制并验证当前 Agent 的
> 受管数据，然后清理当前资料；会话可能随即从“当前”移动到“归档”。操作前请关闭相关
> Agent CLI，并另外保留独立备份。

使用方式：

1. 选择要归档的 Agent。
2. 点击 **创建快照**，可填写便于识别的标签。
3. 归档完成后，可在会话页的“归档”范围查看其中的会话。
4. 需要切换回来时点击 **恢复**。恢复前，应用会为当前资料创建 `auto-*` 自动备份。
5. 确认不再需要后才点击 **删除**；删除快照无法撤销。

认证文件不会写入快照，并会尽量保留当前登录状态，例如 Codex 的 `auth.json`、OpenCode 的
`auth.json` / `account.json`。但快照仍可能包含完整会话、项目路径、提示词和配置，不应上传
到公开位置。

### 指令

指令页只管理 Agent 的**全局指令文件**：

- 选择来源和文件后查看内容。
- 可编辑文件会显示 **编辑 / 保存**；尚不存在的可编辑文件会在首次保存时创建。
- 只读文件不会显示保存操作。

项目级指令不在此页修改，请从具体会话的 **项目上下文**进入。

### 设置

#### 终端与恢复参数

- 选择 `PowerShell`、`pwsh`、`cmd`、`bash` 等可用 Shell。
- 为不同 Agent 配置恢复会话时附加的命令行参数。
- 配置启动终端时注入的环境变量。

环境变量会保存在本机配置中。虽然界面会隐藏工具配置里的敏感值，仍不建议在这里长期保存
高权限密钥；优先使用系统环境变量或专用凭据管理器。

#### Agent 全局配置

可查看或编辑 Agent 声明的全局配置文件。保存会直接写入真实配置，请留意 JSON、JSONC 或
TOML 语法是否正确。

#### 用量价格表

添加模型名前缀匹配规则和输入/输出价格，或点击 **恢复默认**。价格表仅保存在本机。
点击 **重新拉取模型及价格** 会扫描当前索引中的模型，并从 OpenRouter 公共目录补充缺失价格；
已有价格不会被覆盖。网络不可用时会使用内置的少量模型价格作为兜底，未知模型仍标记为未配置。

#### 关于与更新

点击 **检查更新**获取最新版本；发现新版本后可下载并安装。更新包会先通过内置公钥验证，
验证成功后才会安装。

### 主题与语言

侧边栏底部可以切换深色模式和中英文界面。

## 功能支持概览

| 功能 | Claude Code | Codex CLI | OpenCode |
| --- | --- | --- | --- |
| 会话浏览、搜索、恢复 | 支持 | 支持 | 支持 |
| 子代理展示 | 支持 | 支持 | 支持 |
| 指令读写 | 支持 | 支持 | 支持 |
| 规则管理 | 读写 | 只读 | 只读 |
| 记忆管理 | 读写 | 只读，取决于本地数据库 | 暂不支持 |
| 快照归档与恢复 | 支持 | 支持 | 支持 |

实际能力取决于 Agent 版本和本地数据是否存在；界面会隐藏当前来源不支持的操作。

## 安全使用建议

- 第一次使用编辑、删除、快照或恢复功能前，先独立备份 Agent 数据目录。
- 执行快照或恢复前关闭相关 Agent CLI，避免文件仍在写入或数据库被占用。
- 会话、记忆、导出文件和快照都可能包含源码、路径、提示词、命令输出或其他敏感信息。
- 不要把真实会话、认证文件、API key、Cookie 或签名私钥提交到 Git 仓库。
- 修改项目上下文前先检查项目 Git 状态，便于对比和回滚。
- 删除记忆和删除快照都是不可撤销操作。

## 常见问题

### 没有检测到 Agent

先确认对应 CLI 在当前系统用户下至少运行过一次，并已生成默认数据目录。Code Déjà Vu 当前
不会自动搜索任意自定义目录。

### 新会话没有出现

返回控制台点击 **刷新**。如果仍未出现，在控制台或会话页点击 **重建索引**，并保持应用
开启直到索引完成。

### 普通搜索找不到确定存在的内容

普通搜索使用容量受限的快速索引。切换到正确的“当前 / 全部 / 归档”范围，然后使用
**深度全文**扫描源文件。

### 点击恢复会话没有得到预期结果

在系统终端中先确认 Agent CLI 可以直接运行，再检查 **设置 → 终端**中的 Shell、环境变量和
恢复参数。归档会话不能保证可以恢复。

### 用量为空或成本不准确

等待索引完成后刷新。部分 Agent 或旧会话没有 token 字段；未匹配价格表的模型也不会计入
成本。最终费用以服务商账单为准。

### 更新失败

检查是否能访问 GitHub Releases。也可以手动下载最新安装包，并对照 `SHA256SUMS.txt`
验证文件；不要安装来源不明或校验不一致的文件。

### 恢复快照后想回到操作前状态

恢复前会自动创建 `auto-*` 快照。进入 **快照**页找到对应自动备份并恢复；操作前仍建议先
复制一份快照目录作为额外保障。
